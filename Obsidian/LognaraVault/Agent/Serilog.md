# Интеграция Serilog

Parent: [[Agent/LognaraAgent]]

`Lognara-dotnet/src/Serilog.Sinks.Lognara/` - библиотека .NET 8+ с зависимостями Serilog 4.4 и Serilog.Sinks.Http 9.2.1. Публичная точка подключения `WriteTo.Lognara(...)` находится в `LognaraLoggerConfigurationExtensions.cs`. Примеры, ограничения и настройка публикации: `Lognara-dotnet/README.md`. Сборка и NuGet-публикация описаны в [[Repository/CI]].

## Контракт

`LognaraJsonFormatter.cs` формирует канонические timestamp (UTC RFC 3339), level и message, необязательные trace_id/span_id и exception. Свойства сохраняются в attributes с вложенными структурами и типами, включая объект Metrics. Произвольные свойства не повышаются до канонических полей. JSON не содержит буквальных переводов строки: разделители дисковых записей добавляет sink с учётом ОС.

`AgentHttpClient.cs` отправляет JSON-массивы с `application/json; charset=utf-8` на `http://127.0.0.1:7400/v1/logs` по умолчанию. Таймаут 5 секунд, HTTP redirect отключён. Токен relay приложению не нужен; источник добавляет агент. Контракты Rust-компонентов не меняются.

## Доставка

Очередь и повторы реализует Serilog.Sinks.Http. Адаптер HTTP превращает сетевые ошибки и таймауты в отказ доставки, сохраняя уже извлечённую пачку для повтора. Любой 2xx подтверждает доставку, штатный агент отвечает 202. HTTP-ошибки повторяются с backoff; утрата ответа допускает дубликаты.

По умолчанию проверка очереди раз в секунду, до 100 событий на запрос, целевой размер 1 MiB без разделителей, событие до 256 KiB UTF-8. Очередь в памяти ограничена 16 MiB сериализованных событий; переполнение отбрасывает новые события. Это не квота RSS. Дисковый режим включается через bufferBaseFileName: до четырёх файлов примерно по 16 MiB, затем удаляются старые. Для каждого экземпляра нужен отдельный постоянный каталог. fsync для каждого вызова Serilog не гарантируется; durable-гарантия агента начинается после 202. Закрытие logger выполняет финальную попытку доставки.

Обновление библиотеки не переписывает существующие файлы буфера. Восстановление ранее повреждённой очереди выполняется отдельно с резервной копией всего каталога и остановленным приложением; автоматической миграции нет.

## Проверки

`Lognara-dotnet/tests/Serilog.Sinks.Lognara.Tests/SinkTests.cs` использует настоящий loopback HTTP-сервер и изолированные временные каталоги. Проверяет формат, уровни, свойства, trace/span, flush нескольких событий в обоих режимах, лимиты, повторы точного тела при HTTP/сетевых ошибках и восстановление нескольких дисковых событий новым logger. Сквозной Rust-конвейер этими тестами не запускается.
