# Durable spool

Parent: [[Index]]

`Lognara-spool/` — общая синхронная файловая очередь; вызывается из blocking-работников. Каталог блокируется для одного процесса. Группа частей публикуется одним переименованием после fsync файлов и временного каталога; fsync родительского каталога завершается до успешного возврата. Квота байтов и событий проверяется без вытеснения. Индекс ограничен 100000 файлами; agent дополнительно ограничивает его 10922 файлами для резерва 8 MiB. Квота событий не вызывает вытеснение.

Читаются прежние `{seq}-{events}.batch` и новые `{seq}.group/{part}-{events}.batch`. Недописанные `*.tmp` не подтверждались и удаляются при восстановлении. Счётчик `.next` сохраняется независимо от удаления данных. Ошибки чтения, размера, записи и ACK возвращаются вызывающему; файл не пропускается.

`pending/` сохраняет неизменяемое тело отправки и ссылки на исходные части. Он занимает отдельный ограниченный резерв, поэтому полная основная квота не блокирует отправку. Частичный ACK и повторный запуск допускают повтор уже доставленных событий. Удаление pending тоже начинается атомарным переименованием.

| Метод | Назначение |
|---|---|
| `Queue::open(dir: &Path, max_bytes: u64, max_events: u64): Result<Queue, Error>` | Блокирует каталог и восстанавливает подтверждённую очередь. |
| `Queue::open_limited(dir: &Path, max_bytes: u64, max_events: u64, max_entries: usize): Result<Queue, Error>` | Восстанавливает очередь с меньшим бюджетом индекса. |
| `Queue::set_max_events(limit: u64)` | Применяет лимит событий без удаления существующих данных. |
| `wire_budget::estimate(bytes: &[u8], budget: usize): Result<usize, BudgetError>` | Проверяет MessagePack без аллокаций перед созданием модели. |
| `Queue::append_group(parts: IntoIterator): Result<(), Error>` | Сохраняет всю группу атомарно либо не публикует ни одной части. |
| `Queue::read(entry: &Entry, limit: usize): Result<Vec<u8>, Error>` | Читает файл с ограничением capacity и проверкой размера. |
| `Queue::ack(entries: &[Entry]): Result<(), Error>` | Удаляет только подтверждённый префикс очереди. |
| `Queue::save_pending(entries: &[Entry], body: &[u8], limit: usize): Result<(), Error>` | Сохраняет точные байты подготовленной отправки. |
| `Queue::pending(limit: usize): Result<Option<PendingBatch>, Error>` | Восстанавливает отправку и оставшиеся неподтверждённые части. |
| `Queue::clear_pending(): Result<(), Error>` | Атомарно снимает завершённую отправку. |

Тесты проверяют квоты, отмену группы, восстановление legacy, эксклюзивный доступ, сохранение unreadable/oversized файлов и pending после частичного ACK; subprocess SIGKILL до публикации и после durable commit до ответа.
