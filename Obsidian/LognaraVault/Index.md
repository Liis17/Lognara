# Lognara — База знаний

Lognara — система сбора логов: агент в контейнере приложения, relay на машине и центральный core. На Rust реализованы агент (`Lognara-agent/`), relay (`Lognara-relay/`), хранилище с API (`Lognara-core/`) и веб-интерфейс (`Lognara-dock/`).

## Правила обновления базы знаний

При работе с проектом обновляй соответствующий файл, если изменилась архитектура, добавлен компонент, изменились зависимости или конфигурация. Новый компонент → заметка в `Repository/` или папке фактического домена + ссылка здесь. Создавай wikilinks только на существующие заметки.
